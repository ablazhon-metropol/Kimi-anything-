# Health Assistant — Андрей's Personal Health Tracker

Персональный трекер здоровья: вода, сон, шаги, питание, тренировки, напоминания.

## Деплой на Railway

1. Залей файлы из этого репо в свой GitHub
2. На Railway: New Project → Deploy from GitHub repo
3. Railway сам найдет Dockerfile и соберет контейнер
4. Готово — получишь рабочий URL

## Структура

- `index.html` — одностраничное приложение (SPA), все данные в localStorage
- `Dockerfile` — nginx alpine, отдает статику

## Возможности

- Дашборд с прогрессом по всем показателям
- Трекер воды (быстрое добавление 250/500/750 мл)
- Трекер сна (время отбоя/подъема, качество)
- Трекер шагов (ручной ввод, график за неделю)
- Дневник питания (калории, белки)
- Тренировки (кардио, силовая, растяжка, кайт, ходьба)
- Напоминания с повтором (раз/день/неделя)
- Настройки целей и профиля

Все данные сохраняются локально в браузере.
